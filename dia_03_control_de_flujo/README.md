# Día 3 — Control de flujo

**Unidad del programa:** Unidad 3.

## Objetivos del día

- Tomar decisiones en el código con `if`/`elif`/`else`, combinando condiciones con `and`/`or`/`not`.
- Repetir código con `while` (iteración indefinida) y con `for` (iteración definida), controlando el bucle con `break`, `continue` y la cláusula `else`.
- Recorrer listas, diccionarios, cadenas y rangos numéricos, y usar `enumerate()`, `zip()` y funciones built-in de apoyo (`min`, `max`, `sum`, `round`, `abs`, `reversed`, `random`).
- Construir listas y diccionarios en una línea con *list comprehensions* y *dict comprehensions*, filtrando y transformando datos de una cartera de pólizas.
- Leer un traceback de Python de arriba abajo y reconocer los errores más frecuentes al escribir condicionales y bucles (`IndentationError`, `SyntaxError`, `NameError`, `TypeError`, `KeyError`, `IndexError`, `ZeroDivisionError`, `StopIteration`, bucle infinito).
- Usar Claude Code como apoyo para interpretar un traceback completo y depurar con criterio, sin copiar la corrección sin entenderla.

## Orden de los notebooks

1. `01_teoria_condicionales.ipynb` — `if`/`elif`/`else`, expresiones condicionales, *boolean cast*, short-circuit, `IndentationError` y `SyntaxError`.
2. `02_teoria_bucles_while.ipynb` — `while`, `break`/`continue`, cláusula `else`, `input()` simulado, bucle infinito.
3. `03_teoria_bucles_for.ipynb` — `for`, iterables/iteradores, `iter()`/`next()`, iteración en diccionarios, `range()`, `enumerate()`, `zip()`, `min`/`max`/`sum`/`round`/`abs`, módulo `random`.
4. `04_teoria_comprehensions.ipynb` — list comprehensions y dict comprehensions con ejemplos de cartera de pólizas, `eval()` y nota de seguridad.
5. `05_teoria_errores_y_debugging.ipynb` — anatomía de un traceback, galería de errores frecuentes, bloque de IA de debugging asistido.
6. `06_ejercicios.ipynb` — 5 ejercicios de dificultad creciente.
7. `07_soluciones.ipynb` — soluciones comentadas (no la abras antes de intentar los ejercicios).
